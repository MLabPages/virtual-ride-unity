# Current state

最終更新: 2026-09-23

## 現在の状態

- Unity 6000.5.7f1 の Windows 向け実験プロトタイプ。
- 起動時生成の 3D 田園コース、自転車視点、自動操舵、速度・回転数・距離・時間・平均/最高速度の HUD がある。現行景観は `valley-2026.09`。
- キーボード、PCカメラ、Windows BLEケイデンスセンサーの入力を切り替えられる。キーボードは40 km/h、全入力の走行側は45 km/hで上限を設けている。
- カメラ計測では、Windows が認識するカメラを ◀ ▶ で選び（選択は PlayerPrefs に保存）、解析範囲を全体／下半分／左半分／右半分／中央から選べる。真っ暗な映像（2秒）と止まった映像（3秒）はエラー表示にして走行を止める。要約JSONに `camera.deviceName` と `camera.measurementRegion` を記録する。
- カメラとBLEセンサーはケイデンスに4.2 m/回転を掛けて仮想速度へ換算する。カメラ推定範囲は35〜115 rpm（約8.8〜29.0 km/h）、一定速度の比較条件は5〜35 km/h。
- `IRideInputSource` により入力方式を走行ロジックから交換できる。WindowsビルドにはBLE接続ブリッジを同梱する。
- `QA/smoke` と `QA/smoke-final` に既存の画面・ログ・結果 JSON がある。
- 視点の揺れなし・固定視野角、「景色に集中」表示、実験前の視点・音設定、共通スタート位置、停止/再開マーカー、保存結果の表示を備える。CSVは20列のスキーマ2を維持する。

## 既知の注意点

- カメラ方式は照明、服装、背景、カメラ位置で精度が変わる近似推定で、妥当性検証は未完了。
- カメラ方式とBLE方式は基準機器との妥当性照合が未完了。BK9C実機での広告・GATT接続・回転数追従は未確認。
- 初版は自動操舵で、ハンドル操作、分岐、障害物、ゲーム課題は未実装。
- `Builds/`、`Library/`、`Temp/` など Unity の生成物は編集対象・Git 対象を確認して扱う。
