# 木の重なり回避と距離看板（2026-09-25）

木の重なりを指摘された。道沿いの広葉樹、森の針葉樹、遠景の木立は、互いの位置を確認せずに置いていた。`ScenicWorldBuilder` に配置済み領域の一覧を持たせ、木・家・並木を置くたびに登録し、近すぎる場所は見送るようにした（半径和の0.8倍未満を重なりとする）。風車・時計塔・花畑は木より先に場所を確保する。遠景の木立は道から16 m以内と湖の楕円内には置かない。景観版を `valley-zones-2026.09.2` に更新した。

200 mごとに「スタートからの累計距離」の看板を追加した（`DistanceSigns`）。走行距離とコース位置は常に一緒にリセットされるため、差から周回数を求め、同じ看板に周回ごとの累計距離（0.2、…、1.2 km）を出す。文字はフォントを使わず線の四角形で描くので、Questの両目でも同じように表示される。実験設定に「距離看板: 表示／なし」を追加し、記録中は変更不可、要約JSONに `distanceSignsVisible` を記録する。

距離の表示はペース配分や努力量に影響しうる。映像速度の比較では、全参加者・全条件で同じ設定にする。

検証: Windowsビルドとスモークテスト（`QA/signs-smoke2/result.json`: passed）が成功した。看板の手前20 mからの画像で「0.4 km」の表示を確認し、森・草原の木の間隔と設定画面の4ボタン配置を目視確認した。Quest実機での看板の読みやすさは未確認。
