# 2026-09-23 BK9C向けBluetooth LE接続

## 実装

- 下部に「BLEセンサー」画面を追加し、周辺BLE機器を12秒検索して機器名・電波強度・短い識別子を表示する。利用者が選択した機器へ接続する。
- Windows補助プログラム `VirtualRideBleBridge.exe` がBLE GATTを扱う。CSCサービス `0x1816` とMeasurement `0x2A5B` を購読し、累積クランク回転数とイベント時刻の差分からrpmを計算する。
- Unity側 `BluetoothCadenceInput` はセンサー速度・rpmを既存の `IRideInputSource` へ渡す。速度は既存の換算係数4.2m/回転を使い、受信が2.5秒途絶えたら0rpmに戻す。
- WindowsビルドではStreamingAssets内の補助プログラムを同梱する。実験要約に入力方式、機器名、BLE CSCプロトコルを記録し、Bluetoothアドレスは記録しない。
- 記録中の検索・接続・入力切替を拒否する。Bluetoothを選択していて未接続の場合は実験記録を開始させない。

## 検証範囲

- 補助プログラムはWindows RuntimeのBLE APIを参照してコンパイルした。
- 利用者がHUD変更後にWindows Playerを再ビルドした。`Builds/Windows/VirtualRide_Data/Managed/Assembly-CSharp.dll` と `StreamingAssets/Bluetooth/VirtualRideBleBridge.exe` が出力にあることを確認した。Player上のHUD表示とBK9C実機接続は未確認。
- BK9C実機が未到着のため、実際の広告名、CSC公開、GATT通知、計測周期、rpmと反応時間、切断時動作は未確認。
- 実機接続後、センサーの一覧検出、CSC接続、rpm追従、停止時0rpm、切断と再接続、実験CSV/要約の各項目を確かめる。
