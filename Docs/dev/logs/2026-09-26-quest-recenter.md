# Quest 正面合わせ（2026-09-26）

ヘッドセットを外さないと向きを直せず、ずれた向きのまま走ると酔いやすいという実機報告を受けた。既存の `QuestHeadPoseTracking.Recenter()` は起動時とシステム再センタリング時だけ呼ばれ、画面から操作できなかった。

- Quest HUD上部に「正面合わせ（2秒後）」ボタンを追加。左コントローラーのXを1.5秒長押し、または両手のピンチを1.5秒保つ操作でも起動する。HUDが視界外にあっても使える。
- 起動すると走行を一時停止し、2秒後の頭の向きを正面にする。補正中は再開できず、補正後に手動で再開する。記録中は `view_recenter_requested` マーカーを残す。
- 基準の回転を左右の向きだけにした。頭を傾けたまま合わせても景色の水平が崩れず、補正後の自然な上下の視線も残る。
- smokeに、傾けた頭で合わせても水平が保たれ、向きがそろうことの回転検証を追加。Windows smoke `QA/recenter-smoke` は passed=true。
- Windows・Questビルド成功。Quest 3へ `adb install -r` Success、起動プロセスを確認し、取得ログに例外なし。ヘッドセット内の見え方、ボタン位置、長押しの反応、酔いにくさは未確認。
