# 2026-09-02 実験セッション操作

## 目的

記録機能を、試行を混同しにくい実験セッション向けにする。入力切替の固定、制限時間での自動保存、実験者イベント、要約メタデータを足す。

## 変更

- 記録開始後は入力方式とカメラ設定を変更できず、試みた場合は画面に理由を出す。
- 試行時間（秒）を指定でき、経過すると自動で保存する。
- 指示・休息・メモのイベントを `_events.csv` と要約JSON、および時系列CSVの `event_marker` 列へ残す。
- 要約JSONにアプリ／Unity版、開始時入力、カメラ設定、`schemaVersion` 2、`measurementValidated: false` を入れる。
- 保存先は従来の Windows Documents パスを維持し、使えない環境では `persistentDataPath` へフォールバックする。
- カメラ由来の値はHUD上で未検証の推定と明示する。
- スモークテストで入力固定、イベント保存、自動停止を確認する。

## 維持する制約

- カメラ映像は保存・送信しない。
- 入力方式は `IRideInputSource` の境界を維持する。
- 特定メーカーのBluetoothセンサーは実装しない。
- カメラ値の妥当性検証そのものは行わない。
