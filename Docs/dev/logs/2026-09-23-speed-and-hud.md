# 2026-09-23 速度範囲とHUD調整

## 速度範囲の確認

- キーボード入力の上限は40 km/h、入力から景色へ渡す共通の上限は45 km/h。
- 実験の一定速度条件は5〜35 km/h。
- カメラとBLEは4.2 m/回転で換算する。カメラ推定範囲35〜115 rpmは約8.8〜29.0 km/hに相当する。BLEは共通上限45 km/hで制限する。
- 40 km/hはこの換算で約159 rpmに相当する。速度上限は今回変更せず、比較条件の上限35 km/hを維持する。

## HUD調整

- 状態メッセージと操作拒否メッセージの高さを文字数に応じて広げ、折り返した文字が領域外へはみ出しにくくした。
- 計測方式の未検証表示を短くし、記録中バッジを未検証入力の速度パネルと重ならない位置へ移した。
- 景色、入力処理、実験条件、記録データの形式は変更していない。

## 検証

- Unity 6000.5.7f1付属Roslynで `RideHud.cs` をUnity API参照付きで単体コンパイルし、警告・エラーなし。
- Unity Playerでの表示と複数解像度の実機確認は未実施。今回のHUD変更を含むWindowsビルドで確認する。
