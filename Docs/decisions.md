# Decisions

## 2026-08-20: 既存 Docs と引き継ぎ文書を統合する

- リポジトリの既存表記に合わせ、文書は大文字の `Docs/` に置く。
- `AGENTS.md` は入口と必須制約、`current-state.md` は現状、`dev/logs/` は作業履歴に分ける。
- `Docs/SENSOR_INTEGRATION.md` は専用センサー接続の具体的な契約を正とする。

## 既存機能として維持する判断

- まずキーボードで体験を再現できるようにし、カメラがなくても走行確認を可能にする。
- カメラ計測は周期運動の近似であり、速度計測の妥当性を確定したものとして扱わない。
- カメラ映像は PC 内で処理し、保存・外部送信しない。
- 専用センサーの機種決定前はメーカー固有の通信実装を入れない。
